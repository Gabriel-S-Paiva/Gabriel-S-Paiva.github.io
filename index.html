Owned Cloud

v1.0.0 · self-hosted
Self-hosted family cloud storage platform · solo project

A self-hosted Dropbox-style file cloud with role-based auth, storage quota enforcement, and granular folder sharing options.

  • Designed a single-origin Caddy reverse-proxy setup enabling secure HttpOnly cookie session auth over LAN HTTP.
  • Engineered a two-phase chunked upload pipeline with transactional quota reservations.
  • Configured GitHub Actions CI/CD with automated vulnerability scanning (govulncheck, pnpm audit) and Dependabot updates.
  • Achieved 69.2% test coverage on the storage layer via go test. Currently self-hosted on home server hardware.

PlanIt - Travel Planner

2024 - 2025
Data layer, UX research & gamification design · team of 3 1st Place, ESMAD Best Project 24/25

A client-only travel planner covering flights, hotels, and activities, with a gamification layer designed to drive repeat use. Built with an MV architecture persisting to LocalStorage - no backend.
